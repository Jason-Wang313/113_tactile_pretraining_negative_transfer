# Claims

- Mechanism claim: tactile pretraining can create action-critical negative transfer when source tactile features encode contact regularities that invert under downstream friction, compliance, texture, or sensor-bias shifts.
- Method claim: an action-critical mismatch detector plus calibrated tactile feature gate can retain useful pretrained features while rejecting harmful channels.
- Evidence claim: the local benchmark shows the proposed guard beats the strongest non-oracle baseline by `0.106 +/- 0.008` combined-stress success, wins `7/7` paired seeds, reduces harmful transfer by `0.045`, improves tactile-event F1 by `0.056`, and survives ablations.
- Scope claim: the result is strong local evidence for a submission rebuild, not final ICLR-main readiness.
- Unsupported claim explicitly avoided: no claim of real-robot SOTA or external benchmark superiority.
